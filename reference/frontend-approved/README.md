# Approved frontend reference

Developers may implement from this reference, but must not silently redesign it.

The uploaded prototype is preserved byte-for-byte in artifact/. This directory is not an implementation workspace. Production files belong in apps/pos-web. Root/docs duplicate source files remain only inside the immutable snapshot; do not maintain competing editable versions. Wrapper manifest and checksum list are controlled by WS3.

Open artifact/index.html locally to inspect the simulated UX. Demo credentials/data are fictional. No real integration/runtime claims follow from its verification screenshots. Contract corrections are in docs/contracts/PROTOTYPE-MAPPING.md and ADRs 003–004. Never edit the archived contract to make it match production.
