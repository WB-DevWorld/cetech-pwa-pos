# ADR-003: Freeze v1 wire and application contracts

Status: CURRENT. Approval basis: current user's explicit architecture and contract-freeze execution authorization, 2026-09-11; not a claim of historical or production approval.

## Decision
JSON Schema is payload authority; generated TS, shared OpenAPI refs; exact decimal quantity and safe minor money; no standalone P0 InventoryPort; separate PrintPort.

## Rationale
Prevent three incompatible implementations and preserve source UX.

## Supersedes
Prototype types where mapped in PROTOTYPE-MAPPING.md; older InventoryPort P0 suggestions.

## Consequences
Consumers update through the shared contract process. Preserve historical references and provider mappings. All unverified live facts stay UNVERIFIED until CP-04/gate evidence. This ADR does not authorize untested production effects.

## Affected contracts
Money, Quantity, Quote, SalesPort, PrintPort, envelope, journal.

## Affected workstreams
WS1, WS2, WS3; implementation ownership stays in OWNERSHIP.md.

## Provenance
S0 current master prompt; reconciled S1/S2/S3 and targeted S4 where applicable. See docs/source-manifest/DECISION-PROVENANCE.md.
