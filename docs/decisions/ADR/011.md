# ADR-011: CP-04 development baseline and operation-specific gates

Status: CURRENT. Approved by the senior/user's explicit 2026-09-12 instruction and supplied CORE-01 start decision. Recording that decision does not certify runtime safety or production readiness.

## Decision

`https://training.cetechbpa.com` is the current development and integration reference environment. Provider endpoints and environment settings remain configuration; the hostname is not a domain/schema invariant.

- **CP-04 DEVELOPMENT BASELINE: SATISFIED.** The authenticated training audit is sufficient for local implementation against frozen contracts. CORE-01's CP-04 prerequisite is satisfied; CP-05 remains its separate prerequisite. BR-01 local bridge implementation can proceed against the training baseline/contracts.
- **CP-04 WRITE-SAFETY / CUTOVER EVIDENCE: OPEN / DEFERRED.** Issue #4 stays open. Missing production access, database comparison, hardware, mail routing, payment credentials or fiscal facts do not create a blanket coding blocker.
- Each unresolved fact blocks only the operation that actually requires it. Known unsafe training email, uncertain stock/order boundaries and unsanitized data still block affected remote write tests until contained and evidenced. Local synthetic schema/RLS tests do not depend on proving another site's isolation.
- Live bridge installation/authentication, real pricing parity, stock effects, payment execution and release retain their own acceptance gates. Local/mock success never substitutes for that evidence.

Use the [remaining-work checklist](../../runbooks/CP-04-REMAINING-WORK.md) for owners, prerequisites and closure evidence. When production comparison is unavailable, independently isolated local/sandbox services can enable implementation and controlled tests; they do not establish production parity.

## Rationale

Production-specific unknowns were incorrectly being applied to local, provider-neutral development. The training evidence supplies a usable baseline without authorizing real-world side effects.

## Supersedes

The interpretation in the 2026-09-12 CP-04 audit/coordination state that CORE-01 must wait for complete staging-versus-production isolation or production database fingerprints. Historical observations and unsafe-write findings are preserved. ADR-009 release evidence and ADR-008 pricing/preparation gates remain in force.

## Affected contracts and workstreams

Environment/dependency policy; WS1, WS2 and WS3. No change to v1.0.0 domain, wire or port contracts; no new infrastructure or implementation scope.
