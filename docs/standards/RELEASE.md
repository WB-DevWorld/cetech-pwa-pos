# Release standard

60 hours is a target, not permission to ship financial/data faults. Isolated staging, sanitized fixtures, provider sandbox and real hardware rehearsal required. Qualify exact commit/artifact/environment; no rebuild with different dependencies at promotion. Human signs production promotion; no autonomous VitePOS deactivation. NO-GO: duplicate charge/order/refund/restock, unexplained price/tax/stock mismatch, authorization bypass, lost intent/destructive recovery, statutory process gap or missing restore proof. Capability exclusion needs explicit scope/signoff and leaves workflow safe. Prefer code rollback/forward repair while preserving real transactions; never restore an old database over later sales. Stabilize healthy shifts before permanent VitePOS removal.

Owner: WS3. Controlling contracts/ADRs outrank generic examples. Done = evidence.
